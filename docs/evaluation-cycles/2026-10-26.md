## Root cause and local regression

Delivery intentionally moves the original Linear issue to the configured review
state. A later webhook/reconciliation deactivates that issue's lifecycle. The
existing deactivation unconditionally cancelled active runs, including a new,
explicitly approved continuation on its already verified PR.

`LinearReviewContinuationTest` reproduced the exact cancellation before the fix.
The local fix preserves only workflow-v2 Slack/PR-feedback continuations with a
verified prior PR/head, the same Linear team/project and the configured review
state. Removed/cancelled/differently scoped issues and ordinary/unverified work
still cancel. Three SQL tests cover these decisions; they are now required evals.
This fix was discovered after the independent eval-harness review and has author
review plus SQL regressions, not an additional independent reviewer pass.
